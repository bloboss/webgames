# Introduction

WebGames is a collection of single-player, browser-based logic and puzzle games built with Rust and WebAssembly.

- See [Existing Games](./roadmap/existing-games.md) for a catalogue of what's already playable.
- See [Future Games](./roadmap/future-games.md) for the implementation roadmap.
- The repo-root [`TODO.md`](../../TODO.md) tracks future games as a checkbox task list.
